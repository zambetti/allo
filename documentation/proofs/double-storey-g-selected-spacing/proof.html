The columns are fixed. Inherited disables all four trial features. C for rounds only enables ss20 alone. Selected uses ss17=1, ss18=0, ss19=1, ss20=0: B on every plain g advance plus another B only before o / e / c, so B + B = C for go / ge / gc. It does not use ss17 + ss20, which would give B + C = 3B and over-tighten the rounds. Existing kerning stays active.

The selected setting inherits blanket-B effects before spaces and on terminal g. For each isolated preceding control og / ag / ng, glyph origins are unchanged, but its terminal g advance changes by −B. In a combined text run, that advance change shifts later text. The thin rule after “g g” marks the text-run end: both the advance before the space and the final g advance are reduced. Inherited and C for rounds only leave these boundary advances unchanged.

Keep gj under review: in the selected setting its sampled horizontal gap is 28.6425 font units at 800 and 8.3873 at 900, with no computed overlap. No computed overlap does not guarantee comfortable spacing; this sampled gap is not an exact Euclidean distance. No exceptions have been added for gj, spaces, terminal g or other followers. See clearance data and measurement caveats.

This proof covers plain lowercase g and the unaccented round followers o / e / c only. It is not a complete kerning class, accent-spacing proposal or variable-font integration.
